# SCS operating rules

Standalone Sentinels Communication Systems application owned by Sentinels Technology Group.
Read README.md and platform/ACCEPTANCE.md before changes.
Use npm run dev/build; backend setup and security rules live in platform.
Use Firebase Authentication, Firestore, Storage, Functions or Cloud Run, App Check and default-deny rules.
Keep provider credentials and privileged operations server-side.
Preserve existing interfaces, schemas and workflows. Preserve replaced source in local backups.
Production remains disabled pending acceptance and Firebase project configuration.
No deployment, live communications, number purchases/porting or GitHub connection without explicit authorization.
Do not run npm audit fix or npm audit fix --force.
Run production builds, Functions build/lint, emulator tests and focused manual regressions.
